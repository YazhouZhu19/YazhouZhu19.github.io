# 综合分析规则 v1

2026-11-16。主导航“方向研判”改为“分析”，地址为 `#/analysis`；旧 `#/outlook` 链接兼容跳转。新页面包含“主流研究方向”和“小众积累方向”，采用确定性规则，不加载或调用 AI 模型。2026-11-17 起，同一算法在发布环节计算，浏览器读取带明确计算日和来源指纹的完整结果。旧方向页面及其专属偏好已撤下。

## 共同流程

使用完整论文库和已采集的 GitHub／动态记录，独立于论文库搜索、范围及其他筛选。论文仅纳入现有范围分类中的 core 方法研究；来源仅纳入 direct，旧记录没有相关性字段时须有明确医学影像词语。排除无效日期、未来发表记录。先按可靠作品标识（不按相似标题）、仓库规范地址、资讯 URL／原文 URL 传递归并。未识别方向的合格记录仍计入分母；界面显示排除、合并、未分类数量及来源采集状态。已载入数据不意味着来源完整。

固定词典覆盖分割、检测诊断、重建增强、配准、合成转换、基础模型／视觉语言、定量影像／预后七类方向。词语命中来自标题、摘要、来源简介及 README 摘录；检索标签、star 数和模型生成内容不作为主题依据。允许多标签，方向占比不可相加。问题、技术手段及场景按同一记录中的词语共现提取，不把检索关系声称为因果关系或验证结果。每种来源最多展示三条原句，可打开论文详情或原始 URL。

## 第一类：主流研究方向

以界面标注的计算日为截止日，统计 365 个 UTC 日（含首尾）。论文与动态按发表日、仓库按最近提交日；无日期记录不进入近期统计。仓库代表当前活跃项目，论文和动态代表当期产出，三者不能解释为同一种科研资源。

每个方向分别计算论文、仓库、动态在各自来源中的占比，再取三者算术平均作为“三源集中度”。空来源贡献为零，界面同时显示各源计数，以便识别覆盖不足。三个来源等权是首版人工设定，未经标注数据校准。

主流候选须同时满足：至少 3 篇独立论文；至少两类来源分别有 2 条记录；三源集中度至少 5%。其余显示“观察方向”。按集中度排序，同分按固定方向 ID 排序。问题、技术和场景也按各源占比等权排序，分别展示前三项及其证据。

## 第二类：小众积累方向

基于全部历史方法论文构造“方向 × 问题 × 场景”的共现组合。其独立论文数占历史合格论文总数低于 10% 才进入小众池。该定义表示库内低占比，并不证明全领域小众。

全部低占比组合默认保留在列表中，并按积累证据明确分为“证据充分”和“待补证据”。界面可分别筛选两类状态；缺证据不等于方向不成立。满足以下全部条件才标记为“证据充分”：

1. 至少 3 篇独立作品，发表日期跨度至少 730 天，分布于至少 3 个年份。
2. 至少 2 篇摘要同时出现问题、方法、验证、结果线索；带明显否定或计划用语的句子不用于方法／验证／结果条件。
3. 同一数据资源链接在跨度至少 365 天的论文中出现，且摘要有数据开放表述或明确数据平台链接。否定、未来计划及多链接归属不明的情况不用于证明数据积累。
4. 论文 DOI／arXiv 或摘要中的 GitHub URL 明确关联到非归档仓库；仓库创建至少 730 天，最近 365 天有提交。代码作者名字相同、主题相似或摘要引用其他论文 DOI 均不用于关联。

关联动态通过显式论文标识或仓库链接补充展示，不计作独立科学验证。候选按是否满足全部条件、缺口数、论文跨度排序。未满足项保留为“待补证据”并逐条列出缺口。TF-IDF/BM25 的相似代码候选不计入“证据充分”条件。每篇论文可以进入多个细分组合，不能对组合计数求和。

这些是保守筛选线索：“证据充分”仅表示达到现有规则门槛，没有下载数据、运行代码或核验全文；同一资源重复出现和仓库创建时间不能证明持续维护；词语共现不证明逻辑完整。固定词典、日期缺失、论文版本代表选择、链接缺失、来源偏差均可能漏检。没有证据充分候选时仍展示待补证据组合；仅在筛选“证据充分”时呈现该状态的空结果。

输出字段 `evidenceStatus` 为 `sufficient` 或 `pending`；旧字段 `ready` 保留兼容，且始终等于 `evidenceStatus === "sufficient"`。状态改变不重新定义证据门槛。

## 实现与可复现记录

规则：`lib/integrated-analysis.ts`；发布计算：`scripts/analysis-snapshot.ts`；轻量校验与加载：`lib/analysis-snapshot.ts`、`lib/analysis-store.ts`；界面：`components/integrated-analysis.tsx`。分析规则、分母、去重、门槛和证据选择保持不变，原 Worker 保留用于独立规则工具，但不再由分析首屏加载。

`node --import tsx scripts/report-integrated-analysis.ts` 对当前本地快照在固定截止日 2026-11-16 运行，写出 `docs/integrated-analysis-audit.json`。其中包含规则版本、来源采集日期、分母、排除／合并／未分类数、方向依据、前十个小众组合及证据缺口。此命令是规则运行记录，不是准确率评估。

本地 2026-11-09 采集快照的首次试跑：历史独立方法论文 5,330 篇，近期 5,197 篇论文、28,202 个活跃仓库、1,639 组动态；303 个低占比组合，无同时满足全部积累证据要求的候选。该空结果不表示不存在具有积累价值的方向。纯规则运算约 5.9 秒，不含浏览器下载和 Worker 数据复制。

## 验证结果

2026-11-16：606 项 TypeScript 测试、25 项本地数据/API 测试、60 项中英文浏览器回归全部通过。新增规则测试覆盖来源归一化、可靠标识去重、转载传递去重、近期窗口与历史库分离、日期和相关性排除、小众证据链、无关联／年轻／陈旧／归档代码、否定的数据与实验表述，以及输入重排稳定性。浏览器测试确认两类页面、移动端无横向溢出、来源失败阻止分析并可重试，以及新分析页未请求模型运行时。旧地址兼容、页面加载恢复及其他入口回归通过。

TypeScript 类型检查、Vite 生产编译、完整数据发布校验、资源预算、全项目格式检查与差异空白检查均通过。产物位于 `dist/`；浏览器报告位于 `playwright-report/index.html`。这段为 2026-11-16 首版验证记录；筛选准确率仍需独立人工标注评估。


## 2026-11-17 首次加载优化

旧路径在显示分析之前依次读取完整论文库、GitHub 历史与动态历史。本地真实归档共 11,294 篇论文、90,123 条来源记录，所需 302 个数据请求、121,270,517 字节。现在 `copy-data.ts` 用同一个 `analyzeResearch` 生成完整结果（包括全部 303 个词法组合），写入数据站 `data/analysis-summary.json` 和网页 `analysis-bootstrap.json`，另发布 565 字节的 `data/analysis-manifest.json`。完整结果包为 1,429,815 字节；本地同代正常加载共 2 次请求、1,430,380 字节，较旧路径减少 98.82%。若远端更新或网页副本较慢，会额外读取校验后的远端包；发布切换时摘要不匹配只重试一次。

网页副本与远端检查并行，慢副本不会阻塞健康远端。结果、来源计数、采集状态与计算日期整包更新；旧来源或不兼容规则版本不能覆盖已有结果。远端包校验字节数、SHA-256、规则版本和来源指纹。读取失败保留已有结果并允许重试；模块下载失败提供显式页面刷新。首屏历史专题不依赖任何实时源请求。只有点击论文依据或启动 TF-IDF/BM25 检索，才加载完整资料；展开检索工具不会触发下载。

为准确表达已发布计算结果，按钮改为“查看规则分析”；其余导航、页签、卡片、字体、颜色、移动端和深色主题沿用既有 UI。界面显示明确的 UTC 计算日，跨日不会把已发布结果伪装成当天重算；“检查最新数据”读取最新发布包，每次后续数据构建都会重新计算。

`node --import tsx scripts/check-analysis-publication.ts` 使用产物的 UTC 日期重新运行原引擎并逐项比较全部结果，检查 bootstrap/summary 字节与来源指纹；已纳入 CI。真实数据核对记录见 `analysis-publication-check.json`。`node --import tsx scripts/check-native-analysis.ts` 验证冷启动、历史与主流方向、手机和深色界面；记录见 `analysis-loading-browser-check.json`。本机冷浏览器历史首显 532 ms，分析就绪 559 ms，展示结果 99 ms，完整源请求和模型请求均为零。上述时间是本地生产预览测量，不代表互联网访问时延。
