# 信息筛选首版

日期：2026-11-13。此功能在论文库现有主题筛选之后提供可解释的记录比对。它以论文为中心，将 GitHub 和资讯作为关联来源；不对所有新闻、仓库独立进行内容质量评级。

## 使用

进入论文库，先用搜索和现有条件确定候选范围，再打开“信息筛选”。选择收录观察起点和记录截止日，按需“载入跨源资料”，然后“开始比对”。计算使用当前候选集合以及完整论文参照库，在独立 Worker 中运行，可取消。默认观察起点为当前 UTC 日期之前 30 天，截止日为当天。

结果可以按历史记录、跨来源关联、早期相关工作和研究逻辑线索四个条件组合过滤。展开一篇结果可查看判定依据、摘要原句和相关文献，点击论文标题可打开既有详情界面。结果按记录标识排列，不是质量排行榜。原始数据不会删除或被改写。

调整论文条件、日期或载入新的来源数据会使已有结果失效，需要重新比对。结果保存在当前页面内存中；切换离开论文库或刷新页面后不会保留。

## 比对规则

历史比较使用首次发现／采集溯源日期以及 DOI、arXiv、PMID 等作品标识，区分此前已收录、窗口内首次收录、同作品其他记录及时间未知。标题相似、摘要引用同一个 DOI 或共享代码库不能单独证明同一作品。当前资料没有完整旧文本快照，因此不会声称计算过历史摘要差异，首次收录也不代表科学创新。

跨源比较使用显式标识和 URL 关联，对相同 URL 和资讯原文 URL 合并展示。摘要中的引用关联会单独说明，避免将被引用工作的报道当作本论文的报道。载入不完整与没有匹配结果分开表示。论文、新闻和代码之间存在链接，不代表独立科学验证或代码复现成功。

早期相关工作基于完整参照库的稀有标题词索引及任务／模态标签查找更早发表的不同作品。每篇最多使用 8 个词项，每个词项至多对应 128 条记录，展示最多 5 个比较候选；超过频率上限的常见词不参与召回。候选结果提供匹配理由，供人工进一步比较贡献、数据集和实验条件，不自动断言新颖性或性能增量。当前实现不是语义检索或系统综述，可能遗漏措辞不同、标签缺失或未收录的相关工作。

研究逻辑检查以“目标→方法→实验／观察→比较／结果”形成三段原句对照，每侧最多显示 3 句并保留实际命中数。缺少一侧或两侧只命中同一句时显示证据未知；两侧都有独立句子只表示可供对照，不判断论证成立。取消用共同主题词判定承接的规则，避免正常改写触发复核。保留原句中的否定和限定，中英文分别标注，手机上按上下顺序显示。

每一句肯定性的优越性表述单独检查比较对象与带指标名的量化性能线索。证据范围限于该句及紧接、具有显式承接词的结果句；其他位置的背景数字、样本比例和另一项结论不会被借作支撑。缺少线索时提示复核全文。该规则是保守的文本启发式，不能验证实验真实性、数据集可比性或科学结论；较远位置的有效证据仍可能漏检。概念性论文不因摘要没有实验而自动进入复核。

## 时间与来源边界

日期按 UTC 日、包含边界处理。含无效日期或晚于截止日的当前论文记录不会用当前文本冒充历史文本，而会显示未知／证据不足。跨源记录也检查观察、采集、修订和发布等日期。历史截止日不是历史快照恢复功能。

早期工作以发表日期确定先后，并排除已知修订时间晚于候选论文发表日期的参照版本；这仍是对当前库记录的保守比较，不证明当年已经收录或可获得完整相同文本。来源全部载入只表示当前公开数据集已载入，不表示覆盖整个学术领域。

## 工程与验证

核心规则位于 `lib/information-screening.ts`，Worker 位于 `lib/information-screening-worker.ts`，入口和证据展示位于 `components/information-screening.tsx`。现有采集与发布流程、数据格式、个人收藏和 AI 服务接口未改变。

新组件与 Worker 按需加载。资源预算新增三个明确的产物额度，并只按这些额度增加可选 JS／CSS 总预算；原有首页、其他资源和数据容量上限保留。

核心测试覆盖日期、版本身份、转载去重、缺失来源、历史参照范围、摘要线索及否定表达。端到端测试覆盖中英文比对、组合筛选、证据展开、打开论文、失效重算、来源失败重试与移动端宽度。测试使用合成资料，不能据此声称真实筛选精度已得到验证。

首版在隔离 Linux 依赖副本中验证，保留原有 macOS 依赖目录。全量测试通过 615 项（590 项 TypeScript 测试与 25 项本地测试），相关浏览器回归通过 22 项（中英文各 11 项），TypeScript、Vite 生产编译、完整数据发布校验及资源预算检查通过。使用本地 11,294 篇论文、90,123 条来源记录进行一次全部候选比对，返回 11,294 条结果，纯计算约 11.3 秒；不含下载、浏览器 Worker 启动或数据复制时间，不是速度保证或准确率评估。
