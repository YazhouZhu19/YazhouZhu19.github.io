# 论文与代码关联：本地词汇检索

实现版本：`2026-11-16-lexical-v1`。算法只使用当前采集快照中的文本、日期和显式链接，不调用大语言模型、预训练向量模型或外部检索服务。

## 结果含义

- **明确链接**：论文摘要中的 GitHub URL，或仓库记录中的 DOI/arXiv 链接，与论文标识匹配。作品合并时保留全部版本的关联标识，仓库合并时保留全部记录的关联标识。它是原始资料中存在的关联线索，不代表代码已验证、可运行或属于官方实现。
- **候选关联**：TF-IDF 与 BM25 的词汇匹配结果，需人工核对。每篇论文最多展示 3 个候选，已明确关联的仓库不重复进入候选列表，归档仓库不进入候选列表。
- **暂未找到关联**：当前资料没有明确链接，也没有满足候选词语条件的仓库。不代表论文没有开源。

论文统计按“有明确链接 → 仅有候选 → 暂未找到”的优先级互斥计数；一篇有明确链接的论文仍可能显示额外候选。统计项相加等于参与关联的独立论文数。

候选关联不会写入小众方向的代码证据，不会使“待补证据”升级为“证据充分”。小众状态继续使用原来的历史、逻辑线索、长期数据链接和明确关联代码四类门槛；“证据充分”只表示这些规则门槛已满足，不是科学结论已验证。

## 纳入与去重

论文沿用方法研究 core 范围，排除无效/未来日期及 future 异常，使用 DOI/arXiv/其他可靠作品标识合并；不启用标题作者模糊合并。仓库使用直接相关来源，或缺少 relevance 字段但匹配现有医学影像范围的来源；要求有效观察日期且无未来创建日期，按 GitHub owner/repository 地址合并。保留历史记录，不局限于主流方向的近 365 日窗口。

同一作品选择摘要较长的代表记录；仓库选择最近观察的记录，并保留重复记录中的关联标识。返回顺序与并列得分处理均按稳定 ID，避免输入顺序改变结果。

## 分词与候选排序

1. 论文使用标题及原始摘要（缺少时用摘要），仓库使用标题、描述和已采集 README 摘录。移除 URL、DOI、arXiv ID、HTML，转小写后提取长度至少 3 的英语字母/数字词，另保留医学影像模态 CT、MR。
2. 冻结本地英文停用词及通用论文用语表。当前不支持完整中文语义处理；中文内容可能主要依赖明确链接或夹杂的英文词，不能声称中英文检索能力相等。
3. 在本次全部论文和仓库文本上计算文档频率，保留 df≥2、df≤95% 的词；最多取频率最高的 6,000 词。TF-IDF 使用平滑 IDF `log((1+N)/(1+df))+1` 与次线性 TF `1+log(tf)`，文档向量进行 L2 归一化。
4. 每篇论文选择 TF-IDF 权重最高的至多 64 个查询词，归一化查询向量。用倒排表累积 TF-IDF 余弦和 BM25，避免逐论文扫描所有仓库。
5. BM25 使用 k1=1.2、b=.75、正 IDF `log(1+(N-df+.5)/(df+.5))`；这里 N 和 df 来自仓库集合，长度来自停用词过滤后的完整分词，查询词按是否出现计分。
6. 候选至少共享 2 个保留词。两种检索各取前 20，用 [RRF](https://plg.uwaterloo.ca/~gvcormac/cormacksigir09-rrf.pdf) `Σ 1/(60+rank)` 融合；未进入相应前 20 的排序贡献为零。取融合前三，展示最多 8 个共同词以及两个原始检索得分和排名。

共同词数量、RRF 常数和保留数量是当前工程筛选参数，尚未经过新增关联精确率的人工校准。原始分数不是准确率、置信概率或研究质量分数。可能存在通用词相似、任务相似但实现不对应等误关联，因此页面保留“候选待核对”。

## 与此前实验的区别

此前的[对比实验](../eval/analysis-benchmark/README.md)使用分组留出、来源数量限制、仅训练集拟合词表，以及独立的 TF-IDF/BM25 排序来估计已知链接找回效果。本次运行使用完整当前语料构建本地检索索引，增加领域停用词、查询词上限、共享词要求及 RRF 融合。

因此，实验中的 81.5% 或 68.5% 不能转贴为本次融合候选的准确率或召回率。新增候选需要人工标注、独立留出数据和相应 Precision@K/Recall@K 验证，才能声称改进后的真实效果。

## 单文件交付与验证

`scripts/export-integrated-analysis-html.ts` 直接在真实快照上运行方向分析和关联检索，将结果嵌入一个 HTML。默认生成工作区根目录 `OEVRYN-分析-关联与证据.html`；保留此前旧版 HTML。文件本身不请求网络资源，只有点击原文外链才需要网络。

```sh
node --import tsx scripts/export-integrated-analysis-html.ts
node --import tsx scripts/check-analysis-html.ts
node --import tsx --test tests/integrated-analysis-offline.test.ts
```

浏览器核验脚本直接打开 `file://`，禁用网络，检查两类方向状态、关联筛选、搜索、分页、分数展开、桌面与移动布局，并保留截图。离线单元测试额外验证外部文本转义和危险 URL 不会成为链接。
